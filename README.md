# Mutual Fund Analytics

Data pipeline and analysis for Indian mutual fund NAV data: ingestion, validation, SQL analysis, dashboard and reports. Built day by day.

## Status

| Day | Scope | Status |
|---|---|---|
| 1 | Project setup, data ingestion, live NAV fetch, AMFI code validation | Done |

> **Note:** the 10 datasets in `data/raw/` are currently **sample data** generated by `gen_sample_data.py` (with deliberate anomalies for testing). Live NAVs for the 6 large-cap schemes below are real, fetched from [mfapi.in](https://www.mfapi.in/). Real datasets will replace the samples.

## Project structure

```
data/
  raw/          # source CSVs and live NAV pulls
  processed/    # cleaned data
notebooks/      # exploration
sql/            # queries
dashboard/      # dashboard files
reports/        # data quality and analysis reports
data_ingestion.py
live_nav_fetch.py
gen_sample_data.py
requirements.txt
```

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
python live_nav_fetch.py     # fetch live NAV history for 6 schemes -> data/raw/live_nav_*.csv
python gen_sample_data.py    # generate 10 sample CSVs (skip if using real data)
python data_ingestion.py     # profile all CSVs, explore fund_master, validate AMFI codes
```

`data_ingestion.py` prints shape, dtypes and head for every dataset, lists unique fund houses, categories, sub-categories and risk grades, and checks that every `fund_master` scheme code exists in `nav_history`. The summary is written to `reports/day1_data_quality.md`. Edit `CONFIG` at the top of the script if your file or column names differ.
